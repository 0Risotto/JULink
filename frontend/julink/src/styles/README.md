# styles/

Global styling, theme, and variables.

## Files
- `globals.css`: Base global styles
- `variables.css`: CSS variables (colors, spacing)
- `theme.ts`: Theme configuration (light/dark mode)
- `index.css`: Entry stylesheet imported in `main.tsx`

> Each component or feature can still have its own scoped styles (e.g., CSS Modules or Tailwind classes).
