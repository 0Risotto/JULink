# components/

Contains reusable UI components used across multiple parts of the app.

## Structure
- `common/`: Generic, app-wide components (Button, Input, Modal, Loader, etc.)
- `social/`: Reusable components specific to the social media domain (PostCard, Comment, ProfileAvatar, LikeButton)

>  Each component should be self-contained with its own `.tsx`, `.css` (or styled-components), and optional `index.ts`.
